# Simple Training (PWA)

**Открыть:** https://fovae.github.io/training/

Простое приложение для планирования и ведения тренировок. Человек собирает свою неделю из готовых
упражнений, записывает подходы и видит историю. Без аккаунтов, рекламы и cookie: все данные хранятся
только на устройстве. Ставится со ссылки на iPhone (11 – 18), Android и ПК, работает офлайн.

Продукт описан в [`docs/CONCEPT.md`](docs/CONCEPT.md), устройство кода — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
(там же: как добавить упражнение и язык), ручные проверки на iPhone — в [`docs/CHECKLIST.md`](docs/CHECKLIST.md).

Created by Fovae & Claude.

- **Экран установки** — на телефоне в браузере сначала инструкция «На экран «Домой»» (iPhone, Android).
- **Онбординг** — язык (английский по умолчанию), подтверждение 16+, профиль (вес и рост обязательны),
  уровень, план: режим недели, 1–7 дней, пустые дни или шаблон.
- **Сегодня** — следующая тренировка по плану, журнал веса и повторов с предзаполнением, пропуск
  необязательного, заметки, таймер отдыха, экран не гаснет, продолжение прерванной тренировки.
- **План** — 1–7 дней, по дням недели или свободным циклом; упражнения из базы с поиском и фильтрами,
  подходы, диапазон повторов, рабочий вес, отдых, порядок, копирование и очистка дня. Шаблоны «Всё тело»,
  «Поддержание формы», «Рост силы», «Сплит 3+1».
- **Упражнения** — библиотека из 120 упражнений: схема, мышцы, оборудование, техника, ошибки, безопасность.
- **История** — тренировки, заметки, тренировок и объём по неделям, по упражнению — график и рекорды.
- **Советы и уровни** — мягкие подсказки по правилам (прогрессия, снижение нагрузки, восстановление,
  «начни с лёгкого веса»), не больше двух за тренировку, выключаются одним переключателем;
  предупреждение о нереальном весе и опечатке.
- **Настройки** — профиль и уровень, расписание, язык, 11 тем и «Авто», анимации, советы, таймеры, звук, копия данных
  через «Поделиться» и восстановление с откатом, «Delete all data», «About» с документами и лицензиями.

## Стек

Vite 8 · TypeScript (strict) · Preact + Signals · vite-plugin-pwa (Workbox) · IndexedDB через `idb` ·
Manrope (своя копия, `@fontsource-variable/manrope`) · Playwright · ESLint + Prettier.
Никаких CDN, аналитики и запросов к чужим доменам.

## Запуск

Нужен Node.js 20+ (проверено на 24 и 26).

```bash
npm install
npm run dev        # http://localhost:5173 — разработка (service worker выключен)
npm run build      # проверка переводов + типов + production-сборка в dist/
npm run preview    # http://localhost:4173 — production-сборка с service worker
```

Прочие команды:

```bash
npm run i18n:check # все ключи есть во всех языках, формы множественного числа, тексты упражнений
npm run theme:check # контраст WCAG AA во всех темах (12 пунктов с «Авто»)
npm run themes:sheet # контактный лист тем → docs/review/themes.html
npm run legal:check # в юридических текстах нет меток [OWNER / [PLACEHOLDER
npm run licenses   # собрать список лицензий (делается и при сборке)
npm run pics:sheet # контактный лист всех схем упражнений → docs/review/pictograms.html
npm run lint       # ESLint
npm run format     # Prettier
npm run icons      # пересобрать иконки и splash-экраны из design/icon-source.png
npm run test:e2e   # Playwright (первый раз: npx playwright install webkit chromium)
```

## Данные

`docs/BACKUP.md`, пороги веса — `docs/WEIGHT_LIMITS.md`, юридическое — `docs/LEGAL_PLACEHOLDERS.md`.

## Деплой (GitHub Pages)

Каждый push в `main` запускает `.github/workflows/deploy.yml`: lint → проверка переводов → сборка →
e2e-тесты → публикация на GitHub Pages (Settings → Pages → Source: **GitHub Actions**). Публикация — только
после зелёных тестов. Полная матрица iPhone — Actions → Run workflow → «full».

Заголовок коммита (он же название запуска в Actions): `App VerX.X (Короткое описание)`, версия — из
`package.json`.

`base` для Vite берётся из переменной `BASE_PATH` (workflow ставит `/<имя-репозитория>/`). Для своего домена
или Netlify/Vercel собирай без неё (`BASE_PATH=/` по умолчанию) и публикуй папку `dist`.

### Как обновить приложение на телефоне

Приложение само проверяет обновления при каждом открытии (и раз в час). Когда новая версия скачалась,
внизу появится «Доступно обновление → **Обновить**». Во время активной тренировки предложение
откладывается до её завершения. Если долго не появляется — полностью закрой приложение (свайп вверх
в переключателе) и открой снова. Данные при обновлении сохраняются.

## Поведение на iOS и фолбэки

| Возможность | iOS | Что сделано |
| --- | --- | --- |
| Wake Lock | Safari 16.4+, в установленном PWA — iOS 18.4+ | feature detection, повторный запрос при возврате; статус в настройках |
| Звук таймера | только после жеста; в беззвучном режиме Web Audio может молчать | разблокировка первым тапом, `audioSession.type = 'transient'`; всегда есть визуальная вспышка |
| Вибрация | `navigator.vibrate` нет | feature detection, на iOS не вызывается |
| Таймер в фоне | JS замораживается | время считается от `Date.now()`; при возврате показывает верное значение, сигнал — если отдых кончился < 30 с назад |
| Уведомления | Web Push только для установленного PWA, требует сервер | не используются |
| Хранилище | iOS может очистить данные PWA | `navigator.storage.persist()` + статус, экспорт/импорт JSON |
| Splash | только точные размеры экрана | 10 размеров × 2 темы; для неизвестных (новые модели, складной iPhone) — фон `background_color` |

Разрешения экранов сверены с официальными спецификациями Apple (support.apple.com, ноябрь 2026),
таблица — `scripts/ios-devices.mjs`. Для новой модели добавь строку и выполни `npm run icons`.

## Проверка

Автоматически (`npm run test:e2e`, WebKit: iPhone 11 / 13 / 15 Pro Max, Chromium: Pixel 7):
экран установки (iPhone, Android, standalone, ПК), онбординг и валидация, смена языка, редактор плана,
тренировка с перезагрузкой, заметки, история, таймер (подмена часов), экспорт → сброс → импорт, тема,
библиотека, **миграция данных v1** на фикстуре, **обновление установленной версии**, **отсутствие сторонних
запросов и внешних ссылок**, офлайн, ПК, русская версия без английских строк, скриншоты 375/390/430 в обеих
темах, axe (WCAG AA), юнит-тесты определения платформы.

Lighthouse (mobile, production-сборка): Performance 99, Accessibility 100, Best Practices 100, SEO 100.
