# Тренировки · Сплит 3 + 1 (PWA)

Устанавливаемое веб-приложение для тренировочной программы «Сплит 3 + 1». В первую очередь для iPhone
(iPhone 11 – iPhone 18, все линейки), работает и на ПК. Полностью офлайн после первого открытия.

- **Сегодня** — следующая тренировка по циклу 1 → 2 → 3 → 4 → 1, журнал веса и повторов, предзаполнение с
  прошлого раза, подсказка «Пора добавить вес», таймер отдыха, экран не гаснет.
- **Программа** — исходная программа целиком: дни, схемы движений, техника, правила.
- **История** — тренировки (дата, длительность, объём), счётчик недели, графики по упражнениям.
- **Настройки** — тема, кг/фунты, длительность отдыха, звук, wake lock, экспорт/импорт JSON, сброс.

## Стек

Vite 8 · TypeScript (strict) · Preact + Signals · vite-plugin-pwa (Workbox) · IndexedDB через `idb` ·
Manrope (локально, `@fontsource-variable/manrope`) · Playwright · ESLint + Prettier.

## Запуск

Нужен Node.js 20+ (проверено на 26 LTS).

```bash
npm install
npm run dev        # http://localhost:5173 — разработка (service worker выключен)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # http://localhost:4173 — production-сборка с service worker
```

Проверить на iPhone в локальной сети: `npm run build && npx vite preview --host`, открыть адрес из консоли в
Safari. Service worker и установка требуют HTTPS, поэтому полноценно — только после деплоя.

Прочие команды:

```bash
npm run lint       # ESLint
npm run format     # Prettier
npm run assets     # перегенерировать иконки и splash-экраны из assets-src/icon.svg
npm run test:e2e   # Playwright (первый раз: npx playwright install webkit chromium)
```

## Как изменить программу

Всё содержимое — в `src/data/program.ts`. Упражнение выглядит так:

```ts
{
  id: 'lat-pulldown',          // стабильный id — по нему хранится история
  pic: 'lat_pulldown',         // схема из src/pics/defs.ts (необязательно)
  name: 'Тяга верхнего блока к груди',
  sets: 3,                     // рабочих подходов
  reps: [8, 12],               // диапазон; для времени добавь unit: 'sec'
  focus: 'Широчайшие',
  base: true,                  // базовое → отдых 2–3 мин (иначе 60–120 с)
  optional: true,              // можно пропустить (необязательно)
  per: 'на руку',              // подпись к схеме (необязательно)
  tech: 'Техника…',
  alt: 'Замена…',              // необязательно
  link: 'https://…',           // демонстрация (необязательно)
},
```

- **Заменить упражнение** — поменяй поля. Если это *другое* упражнение — дай новый `id`, чтобы его история
  не смешалась со старым. Если только уточнил название/технику — `id` не трогай.
- **Добавить** — вставь объект в нужную группу (`groups[].exercises`). Схема необязательна: без `pic`
  карточка будет без картинки. Новая схема — добавь ключ в `PICS` (`src/pics/defs.ts`), координаты в системе
  200×135, позы `side({...})` / `front({...})`.
- **Удалить** — убери объект. Старые записи в истории остаются, просто не показываются в списке упражнений.
- Подсказка «Пора добавить вес» работает автоматически по `sets` и верхней границе `reps`.

После изменения: `npm run build`, задеплоить, на телефоне появится «Доступно обновление».

## Деплой (GitHub Pages)

1. Создай репозиторий на GitHub и запушь код в ветку `main`.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`: lint → сборка → e2e-тесты → публикация.
   Сайт будет по адресу `https://<user>.github.io/<repo>/`.

`base` для Vite берётся из переменной `BASE_PATH` (workflow ставит `/<имя-репозитория>/`). Для своего домена
или Netlify/Vercel собирай без неё (`BASE_PATH=/` по умолчанию) и публикуй папку `dist`.

### Как обновить приложение на телефоне

Приложение само проверяет обновления при каждом открытии (и раз в час). Когда новая версия скачалась,
внизу появится «Доступно обновление → **Обновить**». Во время активной тренировки предложение
откладывается до её завершения. Если долго не появляется — полностью закрой приложение (свайп вверх
в переключателе) и открой снова. Данные при обновлении сохраняются.

## Поведение на iOS и фолбэки

| Возможность | iOS | Что сделано |
| --- | --- | --- |
| Wake Lock | Safari 16.4+, в установленном PWA — iOS 18.4+ | feature detection, повторный запрос при возврате; статус в настройках |
| Звук таймера | только после жеста; в беззвучном режиме Web Audio может молчать | разблокировка первым тапом, `audioSession.type = 'transient'`; всегда есть визуальная вспышка |
| Вибрация | `navigator.vibrate` нет | feature detection, на iOS не вызывается |
| Таймер в фоне | JS замораживается | время считается от `Date.now()`; при возврате показывает верное значение, сигнал — если отдых кончился < 30 с назад |
| Уведомления | Web Push только для установленного PWA, требует сервер | не используются |
| Хранилище | iOS может очистить данные PWA | `navigator.storage.persist()` + статус, экспорт/импорт JSON |
| Splash | только точные размеры экрана | 10 размеров × 2 темы; для неизвестных (новые модели, складной iPhone) — фон `background_color` |

Разрешения экранов сверены с официальными спецификациями Apple (support.apple.com, ноябрь 2026),
таблица — `scripts/ios-devices.mjs`. Для новой модели добавь строку и выполни `npm run assets`.

## Проверка

Автоматически (`npm run test:e2e`): загрузка, тач-цели ≥ 44 pt, отсутствие горизонтального скролла,
перенос всех 4 дней и схем, проход тренировки, сохранение сессии после перезапуска, предзаполнение и
подсказка прогрессии, таймер (через подмену часов), экспорт → сброс → импорт, тема и `theme-color`,
офлайн-режим, раскладка и клавиатура на ПК, axe (WCAG AA) в светлой и тёмной теме.

Lighthouse (mobile, production-сборка): Performance 100, Accessibility 100, Best Practices 100.

### Ручная проверка на реальном iPhone

- [ ] Safari → открыть сайт → появилась подсказка установки (один раз), крестик скрывает её навсегда.
- [ ] Поделиться → На экран «Домой» → иконка гантели на оранжевом фоне, подпись «Тренировки».
- [ ] Запуск с иконки: splash-экран (светлый/тёмный по теме системы), затем приложение без панелей Safari.
- [ ] Safe areas: шапка не под Dynamic Island/чёлкой, таб-бар над home indicator, в обеих темах.
- [ ] Поля веса/повторов: открывается цифровая клавиатура, экран не зумится.
- [ ] Начать тренировку → отметить подход → таймер; свернуть приложение на 1–2 мин → вернуться: время верное.
- [ ] По окончании отдыха — звук (при выключенном беззвучном режиме) и вспышка.
- [ ] Экран не гаснет во время тренировки (Настройки → «Не гасить экран» → статус «Активно»).
- [ ] Закрыть приложение посреди тренировки → открыть → тренировка продолжается.
- [ ] Авиарежим → приложение открывается и работает; «Демонстрация» показывает сообщение «Нет интернета».
- [ ] Экспорт JSON → share sheet → «Сохранить в Файлы»; импорт этого файла восстанавливает историю.
- [ ] После деплоя новой версии появляется «Доступно обновление»; во время тренировки — только после «Завершить».
- [ ] Переключение тем в настройках меняет цвет статус-бара.
