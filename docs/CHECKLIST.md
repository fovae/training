# Ручные проверки на iPhone

Автотесты покрывают логику (Playwright, WebKit/Chromium), но установку, обновление и системные меню
нужно проверить на настоящем телефоне. Сайт: https://fovae.github.io/training/

## Установка

- [ ] Safari → ссылка → экран «Install Simple Training», крестика нет, вкладки внизу нет.
- [ ] Пока не прокрутил до конца — кнопок нет, внизу «Прокрути вниз», сверху полоска прогресса.
- [ ] Шаги совпадают с телефоном: «⋯» → «Share» → «Add to Home Screen» → «Open as Web App» включён → «Add».
- [ ] «Я установил(а)» → «Готово!»; повторное открытие ссылки в Safari снова показывает «Готово!».
- [ ] Иконка на экране «Домой» → приложение без панелей Safari → сразу онбординг (без экрана установки).
- [ ] Ссылка из Telegram/Instagram → первым шагом «Открой в Safari».
- [ ] «Продолжить в браузере» → онбординг во вкладке; на следующий день экран установки не появляется.

## Этап 2

- [ ] Настройки → Data → «Save a copy»: открывается меню «Поделиться»; «Сохранить в Файлы» и iCloud Drive
      работают, имя файла `simple-training-backup-ГГГГ-ММ-ДД.json`; дата последней копии обновилась.
- [ ] «Restore from a copy» → выбрать этот файл → сводка (тренировки, период, язык, версия) → «Replace
      current data» → данные на месте; «Undo restore» возвращает прежние.
- [ ] Напоминание о копии: после тренировки без копии — плашка на «Сегодня»; «Напомнить позже» прячет её.
- [ ] Темы (до 3.0): все 10 и «Авто» на OLED-экране (тёмные темы без серой подложки, статус-бар меняет цвет);

- [ ] Вес: в жиме гантелей на наклонной ввести явно нереальный вес → окно предупреждения; «Всё верно»

- [ ] Документы: в «About» версии и даты Privacy и Terms, «Open-source licences» открывается офлайн.

## Релиз 3.0

**Сначала — новая иконка.** iOS не обновляет иконку уже установленного приложения.

- [ ] Настройки → Data → «Save a copy» → сохранить файл в «Файлы» / iCloud Drive.
- [ ] Удалить приложение с экрана «Домой» (долгое нажатие → «Удалить приложение»).
- [ ] Safari → https://fovae.github.io/training/ → установить заново по инструкции.
- [ ] Иконка: светлый квадрат с тёмной гантелью по центру, без чёрных углов; на заставке при запуске — та же.
- [ ] Онбординг → шаг «Профиль» → «У меня есть файл» → выбрать копию → «Сегодня» с историей и планом.

**Темы**
- [ ] Новая установка: тема «Авто»; смена светлой/тёмной темы iPhone (Пункт управления) перекрашивает
      приложение сразу, без перезапуска; строка состояния тоже меняет цвет.
- [ ] Все 12 пунктов в «Настройки → Язык и оформление»: у каждой мини-образец, у выбранной — галочка.
- [ ] На OLED: 7 тёмных цветных тем — фон с лёгким оттенком, не серый; главная карточка «Сегодня» —
      градиент, кнопка на ней тёмная с цветным текстом; активная вкладка — цвет темы, остальные серые.
- [ ] «Градиент»: как прежняя оранжевая, главная карточка и большая кнопка — градиент к янтарному.
- [ ] Перезапуск приложения: выбранная тема без белой или чужой вспышки при запуске.

**Плавность**
- [ ] Переключение вкладок: полоска над вкладкой плавно переезжает, экран мягко появляется; повторное
      нажатие на активную вкладку — плавно наверх.
- [ ] Карточка упражнения: открывается справа, «Назад» — слева, список возвращается на то же место.
- [ ] Прокрутка 120 упражнений и истории — без рывков; шапка и нижняя панель не дёргаются.
- [ ] Листы (выбор упражнения, подтверждения, меню действий): выезжают снизу с затемнением, закрываются
      обратно; свайп вниз по шапке закрывает.
- [ ] Таймер отдыха: полоса заполняется плавно, по окончании — вспышка, как раньше.
- [ ] «Настройки → Основные → Универсальный доступ → Движение → Уменьшение движения» включено —
      переходы мгновенные. В приложении «Анимации: Выключены» — так же; «Включены» — анимации есть.

**Safe area и отступы**
- [ ] Модель с Dynamic Island (14 Pro и новее) и модель с вырезом (11–14): шапка не под вырезом, нижняя
      панель над полоской «Домой», последний элемент списка не прячется под панелью и таймером.
- [ ] Поворот в ландшафт (если на iPad/ПК): боковые поля не залезают под вырез.
- [ ] Карточки и плашки нигде не «слипаются»; длинные русские названия переносятся, не обрезаются.

## Обновление «старая установленная версия → новая»

1. [ ] Установленное приложение старой версии открыто, идёт тренировка (отмечены подходы).
2. [ ] Задеплоить новую версию (push в `main`, дождаться зелёного Actions).
3. [ ] Свернуть приложение на 10–20 секунд и вернуться (проверка обновлений идёт при возвращении).
4. [ ] Во время тренировки плашки «Доступно обновление» **нет**, тренировка не прерывается, таймер идёт.
5. [ ] «Завершить» тренировку → появляется «Доступно обновление → Обновить».
6. [ ] «Обновить» → приложение перезапускается; в «Настройки → О приложении» новая версия.
7. [ ] История, план, профиль и настройки на месте.
8. [ ] Если плашка долго не появляется: полностью закрыть приложение (свайп в переключателе) и открыть снова.
