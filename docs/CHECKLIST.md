# Ручные проверки на iPhone

Автотесты покрывают логику (Playwright, WebKit/Chromium), но установку, обновление и системные меню
нужно проверить на настоящем телефоне. Сайт: https://fovae.github.io/training/

## Установка

- [ ] Safari → ссылка → экран «Install Simple Training», крестика нет, вкладки внизу нет.
- [ ] Пока не прокрутил до конца — кнопок нет, внизу «Прокрути вниз», сверху полоска прогресса.
- [ ] Шаги совпадают с телефоном: «⋯» → «Share» → «Add to Home Screen» → «Open as Web App» включён → «Add».
- [ ] «Я установил(а)» → «Готово!»; повторное открытие ссылки в Safari снова показывает «Готово!».
- [ ] Иконка на экране «Домой» → приложение без панелей Safari → сразу онбординг (без экрана установки).
- [ ] Ссылка из Telegram/Instagram → первым шагом «Открой в Safari».
- [ ] «Продолжить в браузере» → онбординг во вкладке; на следующий день экран установки не появляется.

## Обновление «старая установленная версия → новая»

1. [ ] Установленное приложение старой версии открыто, идёт тренировка (отмечены подходы).
2. [ ] Задеплоить новую версию (push в `main`, дождаться зелёного Actions).
3. [ ] Свернуть приложение на 10–20 секунд и вернуться (проверка обновлений идёт при возвращении).
4. [ ] Во время тренировки плашки «Доступно обновление» **нет**, тренировка не прерывается, таймер идёт.
5. [ ] «Завершить» тренировку → появляется «Доступно обновление → Обновить».
6. [ ] «Обновить» → приложение перезапускается; в «Настройки → О приложении» новая версия.
7. [ ] История, план, профиль и настройки на месте.
8. [ ] Если плашка долго не появляется: полностью закрыть приложение (свайп в переключателе) и открыть снова.

## Первый запуск новой версии у владельца (данные v1)

- [ ] После обновления онбординг на русском; на шаге «План» выбрано «Оставить мой текущий план» и показано
      число сохранённых тренировок.
- [ ] После онбординга история и прерванная тренировка на месте.

## Прочее

- [ ] Поля веса и роста — цифровая клавиатура с запятой; повторы — цифровая; экран не зумится.
- [ ] Окно выбора упражнения закрывается свайпом вниз по шапке и кнопкой «Закрыть».
- [ ] Safe areas в обеих темах: шапка не под Dynamic Island, таб-бар над полоской «Домой».
