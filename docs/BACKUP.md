# Копия данных: формат и восстановление

Код: `src/backup/format.ts` (формат, каноническая строка, схема — чистые функции, юнит-тесты
`tests/e2e/backup.unit.spec.ts`), `src/backup/reminder.ts`, `src/features/backup.ts` (кнопки, «Поделиться»).

## Файл

Имя `simple-training-backup-YYYY-MM-DD.json`, MIME `application/json`.

```json
{
  "app": "simple-training",
  "schemaVersion": 3,
  "createdAt": "2026-11-12T10:00:00.000Z",
  "appVersion": "2.3.0",
  "data": {
    "profile": { … } | null,
    "plan": { … } | null,
    "sessions": [ … ],
    "settings": { … }
  },
  "checksum": "sha256:<64 hex>"
}
```

- В `data.settings` не сохраняются временные значения: `tipState`, `lastBackupAt`,
  `backupReminderDismissedAt`.
- Идущая тренировка в копию не входит.
- Файл **не шифруется** (Terms, раздел 7). Куда его сохранить, выбирает пользователь через системное
  меню «Поделиться» (Файлы, iCloud Drive, Google Drive, почта…). Если `navigator.share` с файлами
  недоступен или файл не принят, срабатывает обычная загрузка.

## Каноническая строка и контрольная сумма

`checksum = "sha256:" + hex(SHA-256(UTF-8(canonical(data))))`

`canonical(value)`:

- `null`, строка, число, логическое значение — как `JSON.stringify`.
- Массив: `[` + элементы через запятую + `]`, порядок сохраняется, `undefined` превращается в `null`.
- Объект: ключи **сортируются** по кодам символов (`Array.prototype.sort`), пропускаются ключи со
  значением `undefined` и функции. Результат: `{"ключ":значение,…}` без пробелов.

Одинаковые данные всегда дают одну и ту же строку, независимо от порядка ключей в файле.

## Восстановление

1. Размер не больше 10 МБ.
2. Это JSON-объект.
3. `app` = `simple-training`. Копии этапа 1 (`app: "training-pwa"`, `schema: 2`) переводятся в
   текущий формат.
4. `schemaVersion` не новее приложения. Если новее, приложение вежливо отказывает и предлагает
   обновиться.
5. Строгая схема (valibot, `strictObject`, лишние поля запрещены):
   - строки ограничены по длине, управляющие символы запрещены (кроме перевода строки и табуляции в
     заметках);
   - id в формате `[\w.:-]`;
   - даты в формате ISO;
   - числа в разумных диапазонах: вес снаряда 0–2000 кг, вес тела 20–400 кг, повторы до 10 000,
     возраст 16–120.
6. Контрольная сумма совпадает.
7. Показывается сводка: число тренировок, период, язык, версия. Затем подтверждение «Заменить текущие
   данные».
8. Замена идёт **одной транзакцией** IndexedDB (всё или ничего). В той же транзакции сохраняется
   снимок прежних данных (`kv.restoreSnapshot`). «Отменить восстановление» доступно, пока данные не
   изменились: любая запись профиля, плана или тренировки удаляет снимок.

Данные из файла никогда не вставляются как HTML и не выполняются: интерфейс выводит их только текстом
(Preact экранирует строки, `innerHTML` для пользовательских данных не используется).

## Напоминание

Плашка «Сохрани копию» на «Сегодня» появляется в двух случаях:

- с последней копии прошло 7 дней или больше;
- копии не было, а завершённые тренировки уже есть.

Кнопка «Напомнить позже» скрывает плашку на 3 дня. Push-уведомлений нет.
